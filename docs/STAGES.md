- `compose.yaml` expects `secrets/jellyfin_key`, but the secrets folder does not have it yet. Copy the key there, root
  0600: it lives today at `/volume1/PlexMediaServer/rename/.jellyfin_key`. `docker compose up` fails on a missing
  secret file.
- `config.example.toml` enables every table it holds (`enabled` defaults to true). Deploy only the tables whose cutover
  happens now, and delete each replaced script and its DSM task in the same step.
- Secrets present in `/volume1/docker/projectionist/secrets/` (names only): `anthropic_api_key`, `fanart_api_key`,
  `subdl_api_key`, `tmdb_api_key`, `tmdb_read_token`. compose maps `jellyfin_key` and the TMDB and fanart files so far. The branches
  that use the other two (posters, tonight, subtitles) add their own entries.
